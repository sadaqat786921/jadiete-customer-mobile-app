# Jadeite Systems · Customer app (mobile)

Clickable prototype of **My Jadeite**, the Jadeite Glazing customer phone app (375 × 812): follow your job, dates, order, payments, documents, messages, guarantee and aftercare.

- Sign in with any email and the code **482193**. Pick a demo customer on the sign-in screen.
- `npm install` then `npm run dev`.

See `AGENTS.md` for the structure and the customer flow.
